# Rooted 🌱

A mobile application connecting volunteers with meaningful opportunities in the Baton Rouge area.

## Overview

Rooted simplifies the volunteering experience by providing a centralized platform where users can discover local volunteer opportunities, track their service hours, and seamlessly sign up for events. Whether you're a first-time volunteer or a seasoned community servant, Rooted makes it easy to give back to the Baton Rouge community.

## Features

- **Discover Opportunities**: Browse active volunteer opportunities from local organizations in the Baton Rouge area
- **Organization Map**: Get directions to opportunities near you.
- **Easy Sign-Up**: Register for volunteer events with just a few taps
- **Hour Tracking**: Keep track of your volunteer hours and service history
- **Local Focus**: Find opportunities specifically tailored to the Baton Rouge community

## Technology Stack

- **Framework**: React Native (Expo)
- **Platform**: Android

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn
- Expo CLI
- Android Studio (for Android emulator) or physical Android device

### Installation

1. Clone the repository
```bash
git clone https://github.com/your-username/rooted.git
cd rooted
```

2. Install dependencies
```bash
npm install
```

3. Start the development server
```bash
npx expo start
```

4. Run on Android
- Press `a` to open in Android emulator
- Or scan the QR code with the Expo Go app on your Android device
